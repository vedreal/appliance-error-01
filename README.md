Entry for the [make.fun bounty](https://make.fun/bounty/u-xvader-the-funniest-honest-appliance-error-adec4450): a single line, at most 200 characters — the funniest honest error message an appliance could show.

## The entry

> ERROR: Unbalanced load. It is one sock. I am not spinning until it confesses.

A washing machine reports a real fault — an unbalanced load — in its own flat, put-upon voice. It knows exactly which sock did it, and it will not spin until the sock confesses.

## How it works

`main.py` writes the error message to `/output/entry.txt` (UTF-8, 1–200 characters).

```sh
python3 main.py
```
